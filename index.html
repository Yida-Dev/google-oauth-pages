Personal Google API Auth

This is the Google OAuth application of a personal automation tool. It is used by its owner only, to work with the owner's own Google account.

After the owner grants access on Google's consent screen, the tool can read the owner's Gmail messages, read and manage the owner's Google Analytics properties, read and manage the owner's Search Console sites and sitemaps, verify ownership of the owner's sites, and send indexing notifications for the owner's pages. It does nothing without that authorization.

The application is not offered to the public and has no other users.
